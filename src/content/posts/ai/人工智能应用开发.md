# 人工智能应用开发概览

人工智能应用开发，是把 AI 模型能力嵌入到实际产品与业务流程中的工程过程。它不只是“训练模型”，更包括数据、模型选型、应用编排、部署、评估和持续迭代。当前主流可分为两类：**传统机器学习/深度学习应用** 和 **以大模型为核心的生成式 AI 应用**。

## 一、典型开发流程

1. **问题定义与可行性分析**  
   明确业务目标、输入输出、成功指标，判断用规则、传统 ML 还是大模型更合适。

2. **数据准备**  
   数据采集、清洗、标注、切分、特征工程、隐私脱敏。数据质量通常决定效果上限。

3. **模型选型与开发**  
   - 传统 ML：XGBoost、LightGBM、scikit-learn  
   - 深度学习：PyTorch、TensorFlow  
   - 大模型：调用 API、使用开源模型、RAG、微调、Agent 编排

4. **评估与调优**  
   离线指标如准确率、F1、AUC、BLEU、ROUGE；生成式 AI 还看幻觉率、事实一致性、有用性、安全性。常用 A/B 测试和人工反馈。

5. **部署与集成**  
   封装为 API、微服务、桌面/移动端或边缘服务，接入业务系统。关注延迟、吞吐、成本、并发。

6. **监控与迭代**  
   监控性能漂移、数据漂移、成本、错误率、用户反馈，持续更新模型和提示词。

## 二、核心技术栈

| 层级       | 代表工具/技术                                           |
| ---------- | ------------------------------------------------------- |
| 编程语言   | Python 为主，C++/Go/Java 用于高性能服务                 |
| 数据处理   | Pandas、Spark、Airflow、DVC                             |
| 传统 ML    | scikit-learn、XGBoost、LightGBM                         |
| 深度学习   | PyTorch、TensorFlow、JAX                                |
| 模型生态   | Hugging Face、ModelScope                                |
| 大模型编排 | LangChain、LlamaIndex、Semantic Kernel、Dify            |
| 向量检索   | FAISS、Milvus、Pinecone、pgvector                       |
| 推理部署   | vLLM、TGI、TensorRT-LLM、ONNX Runtime、Ollama           |
| 服务化     | FastAPI、Docker、Kubernetes、Ray、BentoML               |
| 监控评估   | MLflow、Weights & Biases、LangSmith、Prometheus/Grafana |

## 三、常见应用模式

- **预测类**：风控、销量预测、设备故障诊断。
- **视觉类**：图像分类、目标检测、OCR、视频分析。
- **语言类**：文本分类、信息抽取、机器翻译、情感分析。
- **推荐类**：商品、内容、广告推荐。
- **生成式 AI**：写作、代码生成、图像/视频生成、对话助手。
- **RAG 知识库**：文档切分 → 向量化 → 检索 → 重排 → 大模型生成，适合企业知识问答。
- **Agent 智能体**：让模型规划任务、调用工具、访问数据库/API，自主完成多步流程。

## 四、一个典型 RAG 应用架构

用户问题 → 检索器从向量库找相关文档 → 重排器筛选 → 提示词组装 → LLM 生成答案 → 引用来源与安全审核 → 返回用户。  
关键点：文档质量、切分策略、嵌入模型、检索召回率、重排、提示词约束和幻觉控制。

## 五、主要挑战

- **数据**：质量差、标注贵、隐私与合规。
- **模型**：幻觉、偏见、不可解释、版本管理复杂。
- **工程**：延迟高、成本高、并发扩展难。
- **评估**：生成式输出难以自动评估，需结合人工与自动指标。
- **安全合规**：内容安全、版权、数据跨境、行业监管。

## 六、发展趋势

- 多模态模型统一文本、图像、音频、视频。
- Agent 化，从“问答”走向“执行任务”。
- 小模型与端侧 AI，降低成本、提升隐私。
- LLMOps/MLOps 成熟，强调评估、监控和治理。
- 人机协同与 AI 原生应用成为产品设计主流。

## 七、入门建议

先掌握 Python 与 ML 基础，再学习 PyTorch/Hugging Face，随后从大模型 API、提示工程、RAG 和向量数据库入手，最后补齐 FastAPI、Docker、Kubernetes、推理优化与监控。实际开发中，优先用“API + RAG + 提示工程”快速验证，再考虑微调或自训练。

一句话总结：**AI 应用开发 = 业务问题定义 + 数据与模型 + 应用编排 + 工程部署 + 持续评估迭代。**
